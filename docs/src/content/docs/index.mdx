## How it works

<Tabs>
	<TabItem label="Record">
		<Showcase>

		```php
		// On the route, with a 30 minute cooldown per visitor
		Route::get('/posts/{post}', ShowPost::class)
		    ->middleware(RecordViews::using('post', cooldown: 30));

		// Or in a controller
		views($post)->record();
		```

		<ShowcaseOutput kind="record" slot="output" />
		</Showcase>
	</TabItem>
	<TabItem label="Count">
		<Showcase>

		```php
		views($post)->count(); // 48,920

		views($post)->unique()->period(Period::pastDays(7))->count(); // 912

		$trend = views($post)->period(Period::pastDays(7))->compare();
		$trend->percent; // 17.2
		```

		<ShowcaseOutput kind="count" slot="output" />
		</Showcase>
	</TabItem>
	<TabItem label="Chart">
		<Showcase>

		```php
		$series = views($post)
		    ->period(Period::create('2026-10-01', '2026-10-31 23:59:59'))
		    ->countByInterval(Granularity::Day);

		$series->labels(); // ['2026-10-01', '2026-10-02', ...]
		$series->values(); // [41, 44, 47, ...]
		```

		<ShowcaseOutput kind="chart" slot="output" />
		</Showcase>
	</TabItem>
	<TabItem label="Rank">
		<Showcase>

		```php
		// The sidebar of every post
		views(Post::class)->period(Period::pastDays(7))->trending(5);

		// The end of this post
		views($post)->alsoViewed(3);

		// Or order any query by views
		Post::orderByViews()->paginate();
		```

		<ShowcaseOutput kind="rank" slot="output" />
		</Showcase>
	</TabItem>
</Tabs>

## Start simple, scale when you need to

Out of the box every view is one insert and every count is one query. When traffic grows, switch on the next step, one
config key at a time. None of them changes how you query.

<ScaleLadder />

## Works with your coding agent

The package ships guidelines and a skill for [Laravel Boost](https://laravel.com/docs/boost), so an agent records
and counts views the way these docs describe instead of guessing from older versions.

```bash
php artisan boost:update --discover
```

[Set up your coding agent](/eloquent-viewable/getting-started/ai-coding-assistants/)
