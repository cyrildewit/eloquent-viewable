Every view is its own row, so the `views` table grows with traffic. The table in
[Start simple, scale when you need to](/eloquent-viewable/getting-started/introduction/#start-simple-scale-when-you-need-to) lists what to switch on, and
[retention](/eloquent-viewable/scaling/retention/) and [rollups](/eloquent-viewable/scaling/rollups/) keep the table from growing forever. At tens of millions of views a
month, [partitioning](/eloquent-viewable/scaling/partitioning/) lets a whole month go at once.

The repository has a [benchmark suite](https://github.com/cyrildewit/eloquent-viewable/tree/9.x/benchmarks) that times the expensive paths against millions of seeded views on
every supported database. The optional indexes below were measured with it.
